# Nikhil Portfolio — After Photo

Latest final version, including the approved portrait, updated layout and social icons.

## Run locally
Extract the ZIP, open the folder in VS Code, and use Live Server on index.html.
Or run `python3 -m http.server 8000` inside the folder and open http://localhost:8000.

## Edit
- index.html: content
- style.css: layout, themes and animations
- app.js: interactions
- assets/: images and icons, where used

Static HTML, CSS and JavaScript. No npm dependencies or build step required.
Upload folder contents to any static host.
